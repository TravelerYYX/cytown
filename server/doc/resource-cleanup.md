# 资源清理与全局设置

后台独立菜单“全局设置”提供“删除时同时删除资源文件”，默认开启。设置保存在 `system_config.delete_resource_files_enabled`；缺失按开启处理，不依赖 Redis 缓存。GET/POST `/global-settings` 使用 `{ "deleteResourceFilesEnabled": true }`，沿用管理员登录及官方账号只读权限。

## 行为

- 开启：业务删除、资源替换和过期上传回收提交后立即清理无引用文件；存储故障保留任务并自动重试，不撤销已提交的业务删除。
- 关闭：照常处理业务记录，保留文件和存储定位记录，写入永久保留标记；不创建新清理任务，已有待重试任务暂停。
- 重新开启：恢复暂停任务，不扫描历史文件，不追溯删除关闭期间保留的文件。已经发往存储的删除请求允许完成。
- 上传失败、事务回滚补偿、临时文件和存储连接检测不受开关影响。
- 删除账号保留帖子、评论及其资源，释放私有草稿、无引用上传及头像；仍在使用的公共资源保留。
- 删除帖子清理全部评论、回复、原文件、预览、历次封面、下载文件及 HLS 清单/分片。草稿发布转移保护已绑定帖子的资源；共享资源只在最后一个引用释放后清理。

## 数据库与部署

1. 使用部署数据库账号执行 `doc/sql/p26-resource-cleanup.sql`。脚本可重复执行，不覆盖已有开关，不创建历史资源清理任务。
2. 部署 Java 21 构建的后端及管理端 `dist`。首次启动前必须完成迁移。
3. `media_cleanup_task` 保存待清理对象和已完成删除记录，`media_resource_retention` 保存关闭期间的文件保留标记。不要手动清空这两张表：已完成记录用于阻止旧客户端重新绑定已删除 URL。

任务绑定原来的存储配置 ID 和对象键，不依赖当前存储策略。保留原有 `media_storage_config` 及加密密钥，才能清理切换策略前的文件。本地旧版 `/uploads/` 路径按当前上传根目录处理；未登记的内置等级徽章和外部链接不删除。

资源引用写入、删除和转码输出提交按 `media_cleanup_lock` 的单行锁协调，再获取业务行锁。转码在本地完成，上传及发布结果在锁内校验任务身份，避免删除后继续写入文件。存储删除也使用该锁，保证最后一次引用检查与实际删除之间不能新增引用。

定时任务每 30 秒领取最多 100 个到期任务，失败从 30 秒开始退避，最大一小时，持续重试；实例重启后可继续处理。文件不存在视为成功。Windows 上转码进程占用源文件时，首次删除可能暂缓，进程退出后由重试完成。

查看待处理任务：

```sql
SELECT id, storage_id, object_key, attempts, next_attempt_at, error_message
FROM media_cleanup_task
WHERE completed = FALSE
ORDER BY next_attempt_at;
```

## 验证

`scripts/verify-resource-cleanup.py` 仅连接本机 MySQL，通过环境变量读取 `DB_USERNAME` / `DB_PASSWORD`，创建随机命名的 `ciyuantown_account_test_cleanup_*` 数据库，加载完整迁移，运行相关 Java 回归测试，最后删除该临时数据库。不会导入项目数据库的内容、远程存储配置或业务文件。

```powershell
python scripts/verify-resource-cleanup.py
```

Java 21 和 Maven 的默认位置与现有开发脚本一致，可用 `--mysql`、`--maven` 指定可执行文件。管理端执行 `pnpm typecheck`、`pnpm build`。后端打包执行 `mvn -DskipTests package`；测试应通过隔离验证脚本先行执行。

测试覆盖开关默认值/权限/持久化、关闭保留、暂停与恢复、提交后失败重试、回滚、级联删除、两种评论删除模式、草稿共享/发布转移、资源替换、账号内容保留、旧存储配置、本地旧路径、转码并发及过期 URL 拒绝重新绑定。FTP 使用临时服务，OSS/七牛使用 SDK 适配测试，不对真实云端文件发起测试删除。

2026-10-25 验证结果：上述隔离回归共 113 项，112 项通过、1 项按环境条件跳过，失败和错误均为 0；管理端类型检查、生产构建及后端 Java 21 打包通过。本机 `ciyuantown` 已执行 P26 迁移，默认开关为开启，未创建历史清理任务。当前 IDE 启动的后端需重新运行以加载新增服务与接口。
