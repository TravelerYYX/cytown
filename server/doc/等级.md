## 段位释义
1. **初旅（Lv.1-10）**
   如同登上星穹列车的新晋旅客，刚踏入社区，正式开启你的二次元创作与探索之旅。

2. **循迹（Lv.11-20）**
   跟随前人的足迹浏览互动，逐步熟悉社区规则与氛围，是社区活跃的新鲜血液。

3. **逐曜（Lv.21-30）**
   追着星光尝试创作，无论是同人文、小说片段还是小型开源项目，都开始留下专属印记。

4. **织星（Lv.31-40）**
   以创意为线编织内容，成为社区的中坚创作者，产出的作品与项目收获大量用户认可。

5. **耀令（Lv.41-50）**
   践行自身的创作与开拓之路，是社区公认的大佬级人物，能够引领社区内容方向。

6. **归穹（Lv.51-60）**
   抵达星旅途程的终点，是社区的最高荣誉头衔，仅限极少数核心贡献者与传奇创作者拥有。
