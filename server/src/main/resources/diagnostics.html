如果这个页面本身打不开

确认 Java 后端进程已经启动，查看启动日志是否报错；检查 SERVER_PORT、服务器防火墙和安全组。如果通过域名访问，还需检查 DNS、HTTPS 证书和 Nginx 转发路径。

可先在服务器本机访问 http://127.0.0.1:后端端口/diagnostics。本机可访问、外部打不开时，应检查服务器入站网络和反向代理配置。
