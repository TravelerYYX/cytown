# 首页与评论分页等待状态

- 首页追加分页时，单列和瀑布流均在列表底部显示主题蓝 `#00c3ff` 圆环，直径 `36rpx`、每圈 `800ms`。首屏骨架、频道切换及下拉刷新保留原有效果。
- 详情页和图片评论弹层通过各自的滚动容器，在距离底部 `120` 时触发评论组件暴露的 `loadMoreOnReachBottom()`；同时保留“加载更多评论”入口。
- 评论底部在待加载、加载中和全部加载完成时使用相同的最小高度，保证触底后圆环保持可见。“已经到底了”仅在评论分页完成时显示。
- 回复仍点击展开或加载更多，等待时只在回复控制行显示一个圆环。失败保留已有回复，提供点击重试。
- 首页及主评论的自动分页遇到失败后暂停，等待手动重试；已有的请求互斥、页码和过期响应保护继续生效。回复增加相同的 generation 校验，组件卸载后忽略旧响应。
- H5 使用 CSS 动画，App 使用 Element 动画；页面隐藏或组件卸载时释放动画，系统减少动态效果时显示静态圆环。

## 验证

`npm run check:pagination-loading` 使用隔离浏览器上下文和 GET 响应模拟，覆盖首页两种布局、详情评论、弹层评论、回复、重复触底、失败重试、分页完成、过期回复、弹层关闭及减少动态效果；同时断言圆环颜色、尺寸、旋转周期和实际可见位置。结果及截图位于 `artifacts/pagination-loading/`。

H5、Android 编译使用现有开发配置：`npm run build:h5 -- --mode development`、`npm run build:app -- --mode development`。生产配置缺少有效的 `VITE_API_BASE_URL`，未修改环境文件。

已在连接的 Android 设备运行字节码版本，使用临时 GET 响应模拟触底加载第 2 页，保存旋转的两帧、页面隐藏/恢复及分页完成截图。临时请求拦截已恢复，不写业务数据。记录为 `artifacts/pagination-loading/native-report.json`；这不代表正式 APK 验收。
