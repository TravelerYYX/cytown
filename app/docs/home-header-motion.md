# 首页顶部联动动画

首页在实际频道栏抵达紧凑头部前的最后 108rpx 内，按滚动进度平滑显示头像、搜索框并淡出展开区。头像与搜索框分别最多位移 8rpx、12rpx，下滑时反向还原。搜索区使用不透明背景，避免滚动中的资讯文字透过搜索文字。

吸顶节点稳定挂载。原频道栏到达接缝时，固定频道栏接管；隐藏的频道保留占位并停止触摸、焦点及无障碍响应。固定频道栏始终保留 90rpx 高度，只切换显隐和交互，避免原生父节点缩小后裁掉圆角保护层。搜索区背景放在独立容器内，吸顶交接不会再改变背景图片尺寸。两侧的透明圆角保护图片覆盖原生列表先于 JS 更新移动时短暂露出的方形白底。

紧凑头部和圆角保护图片由 `node scripts/build-home-compact-backdrop.cjs` 从原有 `home-banner.jpg` 一次合成后连续切分，保留相同的底色、8% 图片叠加与相邻像素；圆角内部透明。不能用纯色边框替代圆角保护图片，否则会与头部的图片纹理形成明显色块。状态栏高度变化时顶部图片适配搜索容器，圆角图片仍保持 32rpx 高度。

圆角遮罩与固定频道栏放在同一个正常流容器中，遮罩使用容器内的 `top: 0`。不单独以状态栏高度和 rpx 换算计算遮罩顶部：Android 对绝对定位坐标和正常流高度的取整可能不同，900px 宽模拟器上曾导致频道栏从第 177 行开始、遮罩从第 178 行开始，露出一行白线。像素回归必须检查实际接缝首行，不能只检查接缝下方。

`PaneScroll.visualScroll?: (top: number) => void` 为可选回调，同一滚动分区内将事件合并为每帧最多一次的视觉更新。跨越吸顶边界时取消待执行帧，在当前滚动事件中立即更新，避免快速上滑时列表已移动、圆角交接却延迟一帧；反向滚动及回顶同样处理。交接时先显示接管的频道栏，再隐藏原频道栏。首页逐帧直接写入顶部节点样式，仅在显隐/吸顶边界变更响应式状态。其他页面保留原来的分区滚动事件与淡入逻辑。阈值根据头部与频道栏之间的相对几何计算，兼容资讯开关、尺寸变化及路由返回时尚未完成的滚动恢复。

`ActionButton.pressMotion` 默认关闭，首页搜索框、头像、菜单、搜索图标开启。按下缩放至 0.97（100ms），释放、取消或移成滚动手势后恢复（160ms）；隐藏页面时立即复位。滚动位移与按压缩放由不同节点承载。系统减少动态效果时取消位移和按压缩放。

## 验证

- `npm run check:home-header-motion`：H5 320/390/430px × 单列/瀑布流 × 资讯开/关，共 12 组。检查连续与反向进度、阈值往返、稳定节点、频道接缝、按压/取消、头像页面返回、导航切换保留位置、回顶、尺寸变化及减少动态效果。
- `node scripts/verify-android-header-motion.cjs`：实际安卓原生模拟器 127.0.0.1:16384、900×1600，当前真实首页配置。检查隐藏控件无障碍移除、单套频道接管及接缝、搜索可交互、底部导航/头像路由返回、反向滚动和回顶，保存按压/释放截图。
- 首页刷新、瀑布流回归、原生滚动与无障碍边界、性能核心检查。滚动单测另检查视觉回调合帧、回顶刷新、隐藏与销毁取消。
- H5 与安卓 development 资源构建沿用现有环境配置；安卓另外通过 HBuilderX 5.26 字节码原生运行验证。模拟器验证不代表真机手感或正式 APK 验收。

截图、XML 与分端报告在 `artifacts/header-motion/`。H5 自动化使用固定接口数据；安卓使用现有真实数据，不写账号或后端配置。搜索和游戏菜单当前的目标类型未在 `openDestination` 中实现，本次保留原有点击行为，只添加动画；头像仍走原有登录/资料页面。

全量架构检查目前仅剩既有 `static/icons/top-cyan.svg` 与迁移基线哈希不同，本次未修改该图标或放宽检查。为了完成 H5 构建门禁，另外将已有媒体缓存清理调用限制在非 Web 平台，并把图片查看器的 CSS 导入移到样式声明之前。下拉刷新回归发现框架自动作用域使原有内部刷新节点选择器失效，已通过深层选择器恢复隐藏默认刷新占位的行为。
