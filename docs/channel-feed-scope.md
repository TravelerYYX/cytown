# 频道帖子范围与发布开关

后台「运营管理 → 客户端配置 → 频道管理」的新增、编辑弹窗为每个频道提供两个独立开关：

- **显示全部帖子**：开启时，该频道汇总所有频道已发布的帖子；关闭时仅显示归属本频道的帖子。继续按发布时间倒序分页，审核中和下架的帖子不进入公开列表。
- **允许发布**：关闭时，所有用户（包括官方账号）都不能向该频道发布；该频道不会出现在发帖版区列表中，直接提交也会被服务端拒绝。已有帖子仍可浏览。开启后继续遵守「只能管理员发布」权限。

新增频道默认关闭这两个开关。现有频道迁移后保留原发布权限。「发现」是数据库中的普通频道，默认排序最前、显示全部帖子、禁止发布；名称、排序、启停和两个开关均可从后台修改。首页完全使用后台频道列表，默认选中排序第一的启用频道，不再固定插入「发现」。默认发布频道与首页初始选中频道是两个独立概念；默认发布频道必须启用且允许发布。

`home_channel` 新增 `show_all_posts`、`allow_publish` 两列。新增接口省略字段时默认关闭；旧客户端更新时省略字段则保留已有设置。管理端快捷启停提交完整记录，保留两个开关。`GET /app/home/config` 的频道项返回 `showAllPosts`，客户端仍将真实频道 ID 传给 `GET /app/post/list`，由服务端根据配置解析公开列表范围；后台帖子筛选、我的帖子和关注列表保持原有过滤含义。

保存频道后清除首页、发帖配置和帖子列表缓存。首页后台重验发现当前频道的范围改变时重新加载帖子。发帖配置使用 `channel-access-v2:regular/official` 缓存键，避免沿用旧发布规则。
