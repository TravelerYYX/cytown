# 单列列表视频自动播放

设置中的“列表视频自动播放”已接入首页单列、关注、我的发布/收藏和用户主页的帖子列表。双列瀑布保持封面展示，详情继续沿用原来的自动播放设置。

## 行为与实现

- 保留 `settings_video_autoplay`，默认仅 Wi-Fi；网络未知、识别失败或断网时不启动列表视频。网络变化、恢复页面和设置变化会重新判断。
- 按媒体实际矩形计算有效可见面积，扣除固定头部及列表视口以外的区域。至少可见 50% 才能参与选择，距离视口中心最近的候选稳定 180ms 后播放；平局保留当前视频，其次按画面中的排列顺序选择。
- 全局只保留一个列表播放器。切换前先卸载旧表面，再挂载新表面；隐藏、离屏、刷新、换频道、组件复用和卸载会取消旧任务并释放播放器。
- 列表始终静音循环。重新进入播放区域从头播放，点击进入详情。处理中的视频、处理失败或无播放地址的媒体只显示封面。
- 播放失败或浏览器拒绝自动播放时恢复封面，同一次选中期间不重复请求；离开后重新进入可以重试。
- 普通卡片沿用 `MediaSkeleton`，关注卡片沿用原有媒体网格和封面裁切。轻量 `FeedVideoLayer` 复用现有 Web/HLS、App 和微信播放表面。
- `PlaybackOptions` 增加可选 `muted`、`loop`、`objectFit`；默认保持详情原行为。Web 拒绝播放时通过新增 `PlaybackEvent.blocked` 通知列表回退。
- 修复浏览器虚拟列表由空数据变为有数据后可能停留在空渲染区间的问题，并在实测行高变化后通知列表重新测量。

无需修改后端、数据库或设置弹层。

- AudioFlinger 记录显示该 App 仅有一个活动音轨，其 `PortMuted` 为 `true`，左右音量为负无穷。
- 切走标签后，ExoPlayer 日志记录同一实例释放：15:57:57 初始化，15:58:18 释放。
