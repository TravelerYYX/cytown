# 我的栏目切换修复（2026-11-06）

## Android 复查补修

用户反馈 Android 帖子展示区域仍会左右闪动。第一轮只保留了数据和单个列表容器，原生卡片仍在切换时拆卸、复用和重新绑定；原测试等待点击后 80ms 再检查，漏掉了中间帧。补充连续录像后，看到旧卡片短暂插入和底部位置重新布局，不能用稳定状态通过代替切换过程通过。

补修让发布、赞过、评论、收藏各自持有固定的原生列表。隐藏使用 visibility/opacity，保留原生单元格、图片及布局；栏目之间不再交换同一个 RecyclerView 的数据。所有重复头部使用独立布局 ID，非活动列表同步到共享头部位置并停止播放和交互。搜索取消及主标签返回保存实际滚动位置，尚未加载的栏目先显示加载状态，避免短暂露出预建空态。

“我的”帖子图片直接使用已知的 rpx 宽度和间距，绕过挂载后重新测量的通用列宽规则，避免复用样式覆盖首帧宽度。原生列表铺白色底，避免重排时露出灰色父容器。

逐帧复查还捕获过原生可见性命令先隐藏旧面、后显示新面的单帧露底。最终实现先展示新面，将旧面保留在下层两个渲染帧后再隐藏，连续快速切换会取消过期提交。同步滚动不再使用 0.1px 的强制偏移；帖子边距、图片列宽和间距按物理像素对齐，并在窗口变化时重算。

最终图片测试逐次严格比较两个原生列表中帖子与媒体节点的 x/y/width/height，必须完全一致。压缩录像的独立图片纹理采样另允许 1.25 个物理像素差异，并同时检查内容相关度和亮度差异，以捕获单帧空白；该容差不用于放宽原生布局坐标检查。

新增/加强验证：

- `node scripts/verify-mine-channel-smooth-android.cjs`：检查每个栏目返回时保留原列表 ID 和帖子节点 ID，12 次真实点击往返，另验证 3 次真实左右滑动、长列表到空列表以及慢请求隔离。
- `node scripts/verify-mine-retained-frames.cjs`：使用实际加载完成的双图帖子，录制 12 次发布/赞过切换；录像与每帧图片区域稳定性结果在 `artifacts/mine-channel-smooth-20261106/native-media-regression/`。逐帧图片检查不等同于原生 FPS 验收。
- `python scripts/verify-mine-recorded-frames.py`：检查上述录像的全部编码帧，验证图片区域未消失、未发生横向或纵向跳变。
- 原生调试测试使用 `scripts/native-inspector.cjs` 保持单个连接，避免逐次重连反复安装/卸载调试基座的网络观察器；搜索脚本等待所有原生栏目隐藏后再检查搜索完成状态。

评论配图在栏目隐藏时保留已解码图片，不再随 `active` 清空图片源。评论历史、点赞、详情定位、返回与分页通过 `node scripts/verify-comments-android.cjs --history-only` 验证；全量脚本中额外的媒体详情点赞步骤仍出现跨页面夹具路由失效后的登录跳转，未计入本轮通过结果。原生搜索输入、三页分页、范围切换、取消和返回位置的完整回归通过。

原生渲染缓存固定为四个栏目；每个栏目继续使用 list-view 回收长列表。修改前代码另存于 `artifacts/mine-channel-smooth-20261106/v2-originals/`，第一轮及补修前后的诊断录像一并保留。

“发布、赞过、评论、收藏”原先在每次切换时清空帖子并重新请求，H5 用栏目 key 重建整个内容区域，内容同时横移并从 0.35 透明度淡入。Android 对页脚和返回的列表行分别播放动画，第一屏请求还额外等待两帧。这些行为容易露出灰色底层，形成空白、分离和两段切换的体感。

修改后保留 H5 内容根节点与 Android 原生列表，取消这组栏目的内容横移与淡入，保留标签指示条的原有动画。发布、赞过、收藏各自保存列表、分页及更新时间，返回已访问栏目直接显示缓存，过期或互动变更后在后台校验。评论首次激活立即请求，回访继续保留已有记录。缓存持有帖子交互对象，切换账号、管理帖子和卸载时释放或失效，旧请求不能覆盖新栏目。

空列表和首次加载同步保留原生滚动区域高度，异步几何结果按栏目校验。由深处切换栏目时回到吸顶标签下的内容起点，避免长列表缩短造成标签突然回弹。

验证命令（从仓库根目录运行）：

- `node scripts/check-mine-channel-cache.cjs`：实际 setup 脚本与 Vue 响应式测试；覆盖缓存、分页、互动对象持有、过期请求、空列表重新校验、点赞收藏失效、管理后缓存清除、账号隔离和卸载释放。
- `node scripts/verify-mine-channel-smooth-h5.cjs`：320/390/430px 各连续切换 20 次，覆盖内容根节点稳定、白色背景、无内容位移淡入、慢响应隔离、分页保留和长列表转空列表。
- `node scripts/verify-mine-channel-smooth-android.cjs`：连接的 Android 模拟器，uni-app x Vapor bytecode 原生列表，12 次实际 ADB 触摸切换，覆盖缓存命中、列表容器与几何稳定、慢请求隔离、长列表转空列表。脚本恢复原账号存储和 USB 反向转发。
- `node scripts/verify-comments-h5.cjs` 与 `node scripts/verify-comments-android.cjs`：评论内容、分页、返回刷新、错误重试及评论/媒体点赞动画回归。
- `node scripts/verify-mine-search-h5.cjs`：搜索、取消后的列表和滚动恢复、范围切换及慢响应回归。
- 前端目录执行 `npm run check:native-core`、`npm run check:native-scroll` 及 `npm run build:h5 -- --mode development`、`npm run build:app -- --mode development`。

截图、切换采样、结果和修改前源码位于 `artifacts/mine-channel-smooth-20261106/`。这些检查验证当前环境中的切换行为，未以 JS 采样宣称原生 60fps，也不代表正式安装包或所有实体设备的帧率验收。
