# 首页帖子布局

设置 → 首页帖子布局：单列布局 / 双列瀑布布局。仅作用于首页全部频道，关注和我的帖子保持原样。默认单列。

管理后台 → 首页配置 → 默认帖子布局：管理员保存的是未手动选择设备的默认值，不覆盖用户选择。设备选择不随账号同步；退出登录、清除缓存和重启后仍保留。

## 实现与接口

- 独立双列列表按实际高度将新帖子追加到较短列，已有帖子的列归属不因点赞、重验或分页变化。隐藏页面暂停分列，返回可见状态后继续测量。
- 每帖展示首张媒体，封面比例限制在 3:4～16:9，详情继续使用完整原始媒体。多图显示数量；视频只显示封面、播放标记和时长。纯文字帖不添加空封面。
- 点击卡片任意非交互区域（封面、标题/正文、卡片间距、底部作者条的头像/昵称/等级徽标）都直接进入该帖详情；点赞按钮单独处理，不跳转。单列布局的作者头像与昵称同样进入详情，当前没有独立用户主页。
- `GET /home/layout/get`、`POST /home/layout/update` 使用 `{ "defaultFeedLayout": "single" | "waterfall" }`。写接口要求可写管理员账号，拒绝空值和其他字符串。
- `GET /app/home/config` 增加 `defaultFeedLayout`。后台保存后清除 `home-config` 缓存。首页显示、设置显示和下拉刷新会重新获取配置。
- 本地 `settings_feed_layout` 仅保存用户手动选择；`settings_default_feed_layout` 保存最近成功读取的后台默认值。网络失败保留最近默认；旧接口缺字段或返回非法值时使用单列。

## 数据库与构建

已有 `system_config` 表无需修改结构。初始化脚本位于 `ciyuantoen-back/ciyuantown-back/doc/sql/p11-home-feed-layout.sql`，可重复执行，不覆盖现有值。即使尚未执行初始化 SQL，服务也会默认使用单列，并在管理员首次保存时写入配置。

后端要求 JDK 21。本轮 H5/App 构建使用 `--mode development`，沿用项目已有 API 配置，仅供本地验证；未配置或推测生产 API 地址，也未部署。

- 前端及管理后台类型检查通过，管理后台构建、H5 开发环境构建和 App 开发环境构建通过。

- `npm run check:settings`：设置页结构、选择弹层、护眼及自动播放设置、清缓存、退出登录和五档宽度回归通过；脚本使用固定接口数据。

- `HomeLayoutIntegrationTests` 三项、`HomeLayoutCacheTests` 一项通过，覆盖默认回退、合法值保存、非法值拒绝、管理员鉴权、只读限制、真实 Spring 缓存代理的失效行为。数据库集成测试使用开发库并回滚修改，Redis 缓存禁用。
