# 帖子分享（2026-11-06）

帖子详情顶部、底部、图片查看器，以及关注流和个人主页原有分享入口，均可打开分享面板。面板提供「分享给好友」「复制链接」，并保留「转发到动态」。字体沿用项目样式。

好友列表复用关注用户及历史私聊会话，支持按名称搜索、选择、发送、空状态及失败重试。发送失败保留聊天中的待重试消息，同一次面板内重试沿用客户端消息标识，避免重复提交。

聊天新增 `kind: post`，请求仅新增 `postId`，标题、作者、封面和视频标记由服务端从已发布帖子生成。消息返回可空 `post` 对象；在现有 `chat_message.content` 中保存服务端生成的 JSON 快照，无需数据库结构迁移。旧消息保持兼容；撤销清除快照、引用摘要同步失效。会话摘要、后台私聊管理与离线提醒均识别帖子类型。卡片使用方形封面、浅灰信息区、标题及作者，视频显示播放标记，纯文字帖子省略封面。点击进入当前帖子详情，帖子已下架时显示现有不可用提示。

## 复制链接与后台配置

后台「内容管理 → 发布设置 → 帖子分享配置」可设置分享域名，对应 `GET/POST /post-share-settings`，保存在 `system_config.post_share_base_url`。未配置时使用当前后端请求地址；已有默认地址链接继续有效。写操作沿用后台鉴权与只读账号限制。配置独立域名时，需将 `/app/share/` 和相对媒体路径转发至后端。

`GET /app/share/posts/{id}` 返回 `{url,text}`，文案为：

```text
帖子标题 正文摘要... https://分享域名/app/share/p/短编号 打开【次元町】，这篇帖子超精彩！
```

标题最多40个Unicode字符，正文摘要最多28个，超出附加 `...`；合并换行和多余空白，无正文时省略摘要。短编号由帖子ID的36进制表示生成，不依赖第三方短链平台。`GET /app/share/p/{code}` 提供匿名浏览器分享页，展示当前公开内容及媒体；每次重新检查帖子状态，下架或删除返回404，不缓存页面。分享卡片和复制链接生成前均直接检查当前发布状态，再读取详情缓存。

## 分享卡片作者头像框（2026-11-06）

帖子分享的本地待发送卡片及服务端快照新增可空的 `authorAvatarFrame`、`authorAvatarFrameExpiresAt`。卡片作者头像复用 `UserAvatar`，显示头像框并处理过期；作者为当前账号时沿用当前账号最新佩戴设置。旧快照缺少头像框字段时，服务端在读取历史或单条消息时按作者批量查询补齐头像框与过期时间，不改写已保存的快照；已有头像框字段的快照继续沿用原值。商品卡片本次未调整。

`node scripts/verify-shared-card-avatar-frames.cjs` 使用隔离数据检查三个屏幕宽度的头像框比例和卡片裁切、未佩戴和到期隐藏、停留期间自动到期、当前用户设置，以及点击作者区域进入帖子详情。验证截图与报告位于 `artifacts/shared-card-avatar-frames-20261106/`。

Android 旧消息兼容复测：修复前实际聊天接口返回的两个旧帖子卡片均没有头像框字段；补齐后重启本地后端、重新进入聊天，两条旧消息均显示作者的樱雾星环。原生节点图片地址与尺寸保存在 `android-actual-frames.json`，修复前后截图为同目录下的 `android-current.png`、`android-after.png`。本次只读取实际消息，未重新分享或改写聊天快照。`PostShareTests`、`ChatTests`、`ChatReplyTests`、`ChatAdministrationTests` 共36项通过。
